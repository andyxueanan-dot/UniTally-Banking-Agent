## 网站从哪里进？

### 固定在线体验链接（无需安装，推荐）

打开 **[FinPilot 团队网站](https://unitally-team.onrender.com)**，输入组长单独提供的团队口令，即可在手机或电脑体验。网站和模拟账本托管在云端，正常更新、休眠和重启不需要换网址。不要在 GitHub 公布口令，也不要输入真实银行资料。团队 AI 每天合计最多 20 次调用，DeepSeek 费用不包含在免费托管内。

这不是下方的 `localhost` 地址，也不是 GitHub 仓库地址。[云部署说明](docs/development/CLOUD_DEPLOYMENT.md)。旧 `trycloudflare.com` 链接仅为临时试用，请改用上述固定网址。平台免费额度、休眠及网络条件仍会影响可用性，不承诺永久免费或始终秒开。

### 电脑上已经启动过

直接打开：**[http://localhost:5091/bank-agent](http://localhost:5091/bank-agent)**

打不开时，回到下载好的项目文件夹，双击 **`启动银行智能体.cmd`**，等它提示就绪并打开浏览器。

> `localhost` 的意思是“你正在使用的这台电脑”，不能直接发给队友远程访问。无需安装请使用上方固定 HTTPS 链接；下载代码则按下面步骤在自己的电脑运行。GitHub 是代码与说明，不是网站本身。

### 第一次体验（Windows）

1. **安装 Node.js 24**：从 [Node.js 官网](https://nodejs.org/en/download) 下载 Windows 安装程序并安装。这是运行网站所需的软件，不需要学习编程。
2. **下载团队仓库**：点击 [下载银行智能体压缩包](https://github.com/andyxueanan-dot/UniTally-Banking-Agent/archive/refs/heads/main.zip)，解压到普通文件夹。**不要在压缩包里直接双击运行。**
3. **只认一个启动按钮**：双击根目录的 **`启动银行智能体.cmd`**。首次会联网安装项目依赖、生成网页并打开浏览器，需要耐心等待；不用自己输入命令。
4. **先用“离线演示（非 AI）”**：点击功能按钮，或进入“服务中心”填写表单，即可体验模拟业务。**不需要接口密钥、银行账号或会员付费。**

初始演示余额为 **¥12,860.00**。想重新体验时，可点右上角“新演示账户”；不要把重新创建演示数据当成退款或真实交易。

**停止网站**：双击 **`停止银行智能体.cmd`**。只停止本项目启动并核验过的银行演示进程，不关闭其他 Node 项目。关闭网页本身不会停止后台服务。

## 有哪些功能可以看？

| 在哪里 | 可以体验什么 | 特别说明 |
|---|---|---|
| 工作台 / 助手 | 查余额、分析消费、对比上月、准备转账 | 核对收款人和金额后才执行 |
| 账单明细 | 搜索、筛选月份和类别、查看原始记录 | “疑似重复”不等于已证明重复扣款 |
| 卡片管理 | 挂失、解挂、调整消费限额 | 页面验证码是模拟验证 |
| 服务中心 → 订阅与代扣 | 查周期扣款、预计续费、分别取消代扣或会员 | 撤销代扣不等于取消商户会员 |
| 服务中心 → 模拟理财 | 虚构产品比较、教学问卷、申购、赎回 | 不是真实理财，不承诺收益 |
| 服务中心 → 扩展卡服务 | 演示虚拟卡、临时锁卡、渠道限制、额度申请 | 申请为“待审核”，不是已获得贷款或授信 |
| 服务中心 → 多步协作 | 分步骤办理、暂停、恢复、取消剩余步骤 | 敏感操作逐项确认；接管记录未连接真人客服 |
| 服务中心 → AA 与生活计划 | AA 分摊、预约提醒、生日预算、模拟鲜花/蛋糕订单 | 到期不自动付款；模拟他人付款不是真实到账 |
| 操作记录 | 看任务状态、历史回执、导出记录 | 检查实际执行结果，不只看助手说了什么 |

### 第一次建议这样试（约 5 分钟）

1. 点 **“分析账单”**：看消费分类，再展开需要核对的交易。
2. 点 **“转一笔钱”**：准备给小王转 200 元；确认前余额不变，确认后看余额和回执。
3. 点 **“挂失卡片”**：核对尾号，获取并输入页面内演示验证码，再确认。
4. 试试 **“同名收款人”** 和 **“模拟接口超时”**：观察追问与待对账状态，而不是直接显示成功。
5. 进入 **“服务中心”**，挑一项订阅、AA 或生日预算，按页面操作。

反馈时告诉团队：**你点了什么 → 希望发生什么 → 实际发生什么**，最好带截图。不要上传真实账户或个人信息。

## 可选功能：不配置也能体验上面的业务

- **自由聊天**：需要开发队友在后台配置 DeepSeek 密钥，调用会产生供应商费用。离线按钮和业务表单不需要密钥，也不会假装是 AI 回答。请只输入虚构信息。
- **设备验证（通行密钥）**：在服务中心自愿绑定后，敏感操作可用设备验证，必须使用上面的 `localhost` 地址。它不是银行实名核验；不想绑定可以先体验演示验证码。
- **计算沙箱**：需要另装 Python 和专用运行环境。没装时只有这项不可用，**普通队友不必为看银行功能安装 Python**。[交给技术队友的安装说明](docs/development/BANK_QUALITY_PROGRESS.md#计算运行时安装)

## 打不开时怎么办？

| 看到的情况 | 先这样做 |
|---|---|
| 浏览器提示无法连接 | 双击启动按钮并等待就绪；网址只在启动它的电脑上可用 |
| 提示找不到 Node.js | 安装 Node.js 24 后重新双击启动按钮 |
| 首次安装卡住或报错 | 需要网络下载依赖；保留错误窗口截图给技术队友，不要乱删文件 |
| 提示 5091 端口被其他程序占用 | 不要强行结束陌生进程，把提示发给技术队友 |
| 更新文件后仍看到旧版 | 先双击停止，再双击启动；重新启动时会生成当前版本网页 |
| 从旧 `127.0.0.1` 换到 `localhost` 后账户不同 | 正常，这两个地址的浏览器会话分开；不要把会话令牌发给别人 |

## 文件夹不用全看

我们共用 [这个团队仓库](https://github.com/andyxueanan-dot/UniTally-Banking-Agent)：公开可看，受邀队友可修改。**不要共用账号或API密钥。** 修改时各自开分支，确认后合并到 `main`。[协作办法](CONTRIBUTING.md) · [问题反馈](https://github.com/andyxueanan-dot/UniTally-Banking-Agent/issues)

根目录优先关注 **README + 启动/停止两个按钮**。其他文件是运行所需，不用修改或删除。

- `docs/`：功能细节、开发与安全说明；其中 `archive/` 是旧版资料。
- `archive/`：历史脚本、旧工具锁文件和生成文件，不是当前运行入口。
- `data/`：旧版静态参考资料，不是你的银行账户。
- `src/`、`backend/`：网页和后台源码，留给开发队友。
- `scripts/`、`evaluation/`：启动工具和测试资料，普通体验不用打开。
