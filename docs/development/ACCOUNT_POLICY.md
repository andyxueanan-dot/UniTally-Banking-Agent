# 账户规则、验证与审批边界

本模块是比赛原型中的明确规则子集，不是真实银行全量风控或开户系统。

## 可体验的行为

- 我的 → 新建演示账户：选择Ⅰ/Ⅱ/Ⅲ类。创建独立虚构会话，不改变旧账户类别，不删除旧数据。Ⅰ/Ⅱ初始余额12860元；Ⅲ初始1500元。
- 更多服务 → 账户规则与风控：区分余额、可用余额、信用额度、消费限额、账户分类额度及身份验证。当前所有可操作卡片为借记账户的演示入口，没有透支能力；不模拟完整信用卡账单/还款。
- Ⅱ类演示：非绑定出金和入金分别按日1万元、年20万元检查；Ⅲ类演示：余额不超过2000元，出金日2000元、年5万元。
- 出金统计涵盖本演示产生的转账、刷卡及模拟商户订单付款；入金统计涵盖显式AA模拟到账。预置示例账单不是新发生的资金操作，不计入配额。绑定账户例外、真实开户核验、其他银行渠道、贷款等未覆盖。
- 检查贯穿草案、确认和对账；待对账转账占用限额，对账排除当前任务自身后重新核验，不重复扣款或重复统计。
- Ⅲ类演示不开放理财申购或信用业务意向，是本原型保守业务范围。不可把它理解为任何Ⅲ类户现实中都不能有银行小额贷款。
- Ⅰ类未设置统一分类金额上限，不代表无限制，仍检查余额、卡日限额及权限。没有把PDF中“非柜面通常5000—10000元”当作所有银行统一规定。

## 信用业务不是借记卡提额

当前“信用业务意向”只记录待人工审核的独立申请。余额、消费限额、已获信用额度均不改变；没有真人客户经理或真实银行授信系统接入。普通任务完成回执仅代表申请记录成功，不代表审核批准。

## 身份验证不等于业务资格

通过验证码/设备验证后仍检查业务范围和限额。未接入真实短信、人脸或U盾；公网仍明确标记页面验证码为模拟验证。未宣称补齐生产强认证或真实人工审批。
