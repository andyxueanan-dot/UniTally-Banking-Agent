# 旧版 Firebase 部署说明（脱敏存档）

当前银行演示不需要 Firebase 或邮件服务。体验请看 [仓库首页](../../README.md)。

旧部署文档包含疑似邮件服务密钥，新仓库不保留该值，也不携带旧提交历史。需要维护旧记账功能时，请使用你自己有权使用的服务配置；不要在源码、文档或提交记录中填写真实密钥。

旧文档中的配置示例已替换为占位符，仅用于说明字段，不是经过本轮验证的部署步骤：

```text
resend.api_key = YOUR_OWN_EMAIL_SERVICE_API_KEY
```

如果旧密钥曾公开，应由其所有者在对应服务控制台撤销或轮换。新仓库删除副本并不能撤销已公开的密钥。
